## 🚀 Selected Projects

### [MLOps: Portfolio Optimization](https://github.com/Nattawut30/MLOps-Portfolio-Optimization-Python)

- End-to-end MLOps pipeline for portfolio optimization and quantitative risk modeling.
- Financial mathematics and portfolio allocation using Black–Litterman and Risk Parity.
- Risk analysis using Value at Risk (VaR) and Conditional Value at Risk (CVaR).
- Reproducible workflows with MLflow and GitHub Actions.

[Live Demo](https://nattawut-port.streamlit.app/)

### [Black–Scholes PDE Solver](https://github.com/Nattawut30/Black-Scholes-PDE-Python)

- European option pricing using the Black–Scholes model.
- Numerical pricing methods, including finite differences and Monte Carlo simulation, for European and American options.
- Implied volatility, option Greeks, and interactive visualizations.

[Live Demo](https://nattawut-blsm.streamlit.app/)
